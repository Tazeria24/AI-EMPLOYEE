# Task 00 — Foundation

## Objective
Create the production-ready application foundation.

## Dependencies
None.

## Requirements
- Initialize Next.js App Router + TypeScript.
- Configure Tailwind and shadcn/ui.
- Connect Supabase safely.
- Establish environment variable conventions.
- Create base layouts and UI primitives.
- Configure linting and test framework.
- Create a clean README.
- Add basic health-check capability.

## Non-goals
No auth, billing, WhatsApp, AI agent, or business features yet.

## Acceptance criteria
- App runs locally.
- Production build succeeds.
- TypeScript passes.
- Lint passes.
- Test runner executes.
- Secrets are not committed.
- README explains setup.
