# Task 09 — Website Widget

## Objective
Allow businesses to embed the AI employee on their website.

## Dependencies
Task 06 and Task 07.

## Requirements
- widget UI
- public config
- anonymous visitor session
- conversation creation
- embed script
- product recommendations
- conversion tracking
- rate limiting

## Security
Public endpoints must expose only safe business data.

## Acceptance criteria
A business can generate/install the widget and a visitor can have a complete AI conversation that appears in the dashboard.
