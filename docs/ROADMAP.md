# 60-Day MVP Roadmap

## Phase 0 — Validation
Before heavy implementation, interview at least 20–30 target businesses and validate repetitive customer-support/sales pain.

## Milestone 00 — Foundation
Repo, Next.js, TypeScript, styling, Supabase connection, env handling, base UI, lint/test setup.

## Milestone 01 — Authentication
Signup, login, logout, reset, verification, protected routes, SSR sessions.

## Milestone 02 — Multi-tenancy
Organizations, membership, roles, business profile, RLS, tenant-isolation tests.

## Milestone 03 — Products
Categories, product CRUD, search, inventory fields.

## Milestone 04 — Knowledge
FAQs, policies, documents, chunks, embeddings, retrieval.

## Milestone 05 — AI Agent
Provider abstraction, prompts, retrieval, tools, guardrails, evaluation suite.

## Milestone 06 — Conversations
Conversation/message data model, dashboard chat, realtime updates, takeover/release, customers.

## Milestone 07 — Leads
Pipeline, lead detail, events, scoring/intent fields, conversation-to-lead capture.

## Milestone 08 — Automations
Scheduler, triggers, follow-up generation, max-two-follow-up rule, notifications.

## Milestone 09 — Website Widget
Widget UI, backend, embed script, visitor sessions, product recommendations, conversion tracking.

## Milestone 10 — WhatsApp
Meta Business setup, verified webhook, inbound/outbound messages, AI response, human takeover, idempotency.

## Milestone 11 — Billing
Plans, checkout, subscription state, usage events, limits, payment webhooks.

## Milestone 12 — Monitoring + Security
Sentry, PostHog, rate limiting, auth/RLS audit, webhook verification, prompt-injection tests, production hardening.

## Milestone 13 — Beta
Internal QA, load checks, onboarding polish, 5–10 beta businesses, feedback loop, release candidate.

## 90-day extension
Month 3: beta -> sales -> content -> public launch.

Targets are operating goals, not guaranteed outcomes:
- 10+ active beta businesses
- 5+ paying customers
- first recurring revenue
- repeatable outbound process
- documented retention/activation signals
