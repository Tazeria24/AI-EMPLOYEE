# UX Specification

## Design direction
Modern, premium, calm B2B SaaS. Avoid generic AI-dashboard aesthetics.

Priorities:
- clarity
- speed
- trust
- obvious next actions
- strong typography
- useful empty states
- responsive layout

## Main navigation
Overview
Conversations
Customers
Leads
Products
Knowledge
Automations
Analytics
Settings
Billing

## Onboarding
Step 1: business profile
Step 2: products
Step 3: FAQs/policies
Step 4: activate AI
Step 5: install widget
Step 6: test conversation

Show progress and make the first successful AI conversation easy.

## Dashboard
Prioritize:
- conversations today
- active leads
- follow-ups due
- conversion signals
- AI/human activity

Avoid vanity metrics.

## Conversation UI
- clear customer identity/channel
- message timeline
- AI/human state
- takeover control
- lead context
- relevant product context
- escalation reason

## Product UI
Fast CRUD.
Search/filter.
Stock visibility.
Category organization.

## Knowledge UI
Simple document/FAQ/policy entry.
Show processing status.
Allow reprocessing.
Make source of AI answers understandable where useful.

## Accessibility
Keyboard navigation.
Labels.
Focus states.
Readable contrast.
Responsive behavior.
Meaningful error messages.

## States
Every data-driven surface should consider:
- loading
- empty
- success
- error
- permission denied
